# Q3 Firmware Release Notes

## Version 4.2.1 (October 2026)

Fixes the known issue in 4.2.0 where devices on the guest network were disconnected every 24 hours. Improves the stability of satellite nodes after a power cut.

## Version 4.2.0 (September 2026)

Adds WPA3 transition improvements for older laptops. Fixes false E-310 alerts when a satellite node restarts. Known issue: devices on the guest network may be disconnected every 24 hours; as a workaround, turn off Guest network auto-rotation in the app.

## How updates are installed

Routers install new firmware automatically between 2 a.m. and 4 a.m. local time. Updates are released gradually, so it can take up to two weeks before every router receives a new version.

## Version 4.1.3 (June 2026)

Fixes a problem where the status light stayed amber after the internet connection came back. Improves parental controls scheduling.
